# 🎬 CineVerse AI
### AI-Powered Movie Recommendation & Analytics Platform

**Discover movies intelligently. Explore the data. Compare the models.**

CineVerse AI is an interactive, content-based movie recommendation and analytics platform built using Python, Natural Language Processing (NLP), Machine Learning, and Streamlit. It helps users discover movies similar to their interests by analyzing movie metadata and comparing three recommendation approaches: CountVectorizer, TF-IDF, and Sentence-BERT.

Beyond recommendations, the platform provides an analytics dashboard, an interactive dataset explorer, and a dedicated model comparison module, bringing movie discovery and data analysis together in one application.

🌐 **Live Demo:** [CineVerse AI — Try the Application](https://movie-recommendation-system-sahibz-app.streamlit.app/)

## ✨ Key Features

### 🎥 Intelligent Movie Recommendations
- Select a movie from the available collection.
- Generate content-based recommendations using three NLP techniques.
- Choose the number of recommendations to display.
- View similarity scores for recommended movies.
- Explore movie details, including genre, release year, rating, director, cast, and overview where available.

### 🤖 Three Recommendation Models

**1. CountVectorizer**

Converts textual movie information into word-frequency vectors and identifies movies with similar vocabulary.

**2. TF-IDF**

Assigns importance to distinctive terms while reducing the influence of common words, enabling more meaningful text-based comparisons.

**3. Sentence-BERT**

Uses 384-dimensional semantic embeddings to capture contextual relationships between movie descriptions and identify movies with similar meanings or themes.

All three approaches use cosine similarity to compare movie representations and rank recommendations.

### 📊 Analytics Dashboard
Explore patterns and trends in the movie collection through interactive visualizations, including:
- Top movie genres
- Average ratings by genre
- Director analysis
- Movie production trends by decade
- Rating distribution
- Ratings versus vote counts
- Other dataset-derived insights

### 📚 Dataset Explorer
- Browse movie records interactively.
- Search for movies by title.
- Explore dataset statistics and missing values.
- Inspect descriptive statistics.
- View information about individual movies.
- Examine the structure and characteristics of the underlying dataset.

### ⚖️ Model Comparison
Compare recommendations generated by CountVectorizer, TF-IDF, and Sentence-BERT for the same selected movie. This makes it possible to observe how different text representations influence the results.

### 🧭 Multi-Page Interface

## 🧠 How It Works

CineVerse AI follows a content-based recommendation pipeline.

```text
Movie Dataset
      ↓
Data Cleaning & Preprocessing
      ↓
Text Representation
      ↓
┌─────────────────┬─────────────┬───────────────┐
│ CountVectorizer │   TF-IDF    │ Sentence-BERT │
└─────────────────┴─────────────┴───────────────┘
      ↓
Cosine Similarity Calculation
      ↓
Similarity-Based Ranking
      ↓
Top-N Movie Recommendations
      ↓
Interactive Streamlit Interface
```

The application uses preprocessed movie data and stored model representations. When a user selects a movie, the system retrieves its representation, calculates similarity against other movies, ranks the results, and displays the most similar titles.

## 🚀 Run Locally

### Prerequisites

- Python 3.11 or another Python version compatible with the pinned dependencies.
- Git
- pip

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/bsm2006/Movie-Recommendation-System.git
```

**2. Navigate to the project directory**

```bash
cd Movie-Recommendation-System
```

**3. Create and activate a virtual environment**

macOS / Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

**4. Install dependencies**

```bash
python -m pip install -r requirements.txt
```

**5. Run the application**

```bash
streamlit run app.py
```

The application will open in your browser, usually at:

```text
http://localhost:8501
```

### Important

The recommendation engine requires the prepared files in the `models/` directory. Ensure these files are available locally before running the application. If they are excluded from GitHub because of file-size limits, obtain them from the project's designated source.
